# Customer Segmentation Analysis

## 📌 Project Overview

Customer Segmentation Analysis is a data analytics project that uses RFM (Recency, Frequency, Monetary) analysis to segment customers based on their purchasing behavior.

The project helps identify valuable customers, customers at risk, dormant customers, and price-sensitive/low-value customers.

## 🎯 Objectives

- Analyze customer purchasing behavior
- Segment customers using RFM analysis
- Identify high-value customers
- Analyze customer revenue by segment
- Understand customer distribution
- Create an interactive Power BI dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook
- Power BI
- CSV
- RFM Analysis

## 📊 Customer Segments

The analysis identifies four main customer segments:

- 🏆 Champions
- ⚠️ At Risk
- 😴 Dormant / Lost
- 💰 Price-Sensitive / Low-Value

## 📈 Dashboard

The Power BI dashboard includes:

- Total Customers
- Total Revenue
- Average Order Value
- Customer Distribution by Segment
- Customer Count by Segment
- Revenue by Customer Segment
- Recency vs. Monetary Value by Customer Segment
